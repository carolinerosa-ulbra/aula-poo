# Documentação do projeto (/doc)

> Sistema de Estacionamento — projeto de demonstração · Fundamentos de Programação Orientada a Objetos · ADS · ULBRA · 2026/2

Esta pasta reúne a documentação do projeto conforme ele evolui ao longo do semestre — do planejamento inicial (Atividade 1) até a entrega final (AS).

## Estrutura

```
docs/
├── planejamento.md           # domínio, problema, usuários, funcionalidades (Atividade 1)
├── backlog.md                # backlog atualizado a cada incremento
├── AI.md                     # registro cumulativo de uso de IA (AP1, AP2, AS)
└── diagrama-classes/
    ├── diagrama-v1.png       # versão inicial (Atividade 2, Encontro 2)
    ├── diagrama-ap1.png      # versão na entrega da AP1 (Encontro 5)
    ├── diagrama-ap2.png      # versão na entrega da AP2 (Encontro 10)
    └── diagrama-as.png       # versão final (AS, Encontro 15)
```

## Convenções

- **Diagramas de classes**: manter uma versão por checkpoint (não sobrescrever), nomeada com a etapa que representa. Isso permite mostrar a evolução do projeto nas apresentações de AP1, AP2 e AS.
- **Atualização**: sempre que uma atividade semanal alterar a estrutura de classes, atualizar o diagrama corrente antes de fazer a entrega final daquela semana.
- **backlog.md**: reflete o estado atual do backlog — o que já foi feito, o que está em andamento, o que ainda falta. Reordenar por prioridade conforme o projeto avança.
- **AI.md**: documento cumulativo, criado na AP1 e atualizado nas entregas seguintes — não substituído a cada etapa. Reúne o histórico de uso de IA ao longo de todo o projeto, complementando as declarações pontuais de cada entrega.

## O que NÃO fica aqui

As declarações de uso de IA das atividades semanais (1 a 15) ficam no README.md principal do repositório ou na Ficha Padrão de Entrega enviada no Aula — não é necessário duplicá-las nesta pasta. O AI.md aqui é reservado ao registro consolidado das entregas grandes (AP1, AP2, AS).
